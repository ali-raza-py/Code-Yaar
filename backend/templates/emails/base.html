{% comment %} Shared Code Yaar email layout. Event templates extend this file and override: preheader — invisible inbox-preview line eyebrow — category pill in the brand band (falls back to `eyebrow`) heading — the email's headline salutation — greeting line body — event copy (defaults to one paragraph from `message`) extra — free-form content after the body note — advisory callout (defaults to `note` + `note_tone`, see _note.html) cta_label — the button caption (the link itself always comes from `cta_url`) footer_note — the small-print paragraph above the footer links Context every event passes through learning.services.email_service: cta_url / cta_label / eyebrow, info_rows [[label, value], ...], plus the brand links (dashboard_url, preferences_url) and `unsubscribe_url` for campaign mail. Layout is table-based with inline styles so Gmail, Outlook and mobile clients render it identically; `color-scheme` is pinned to light because this palette is built for a white card on a light canvas and client dark-mode inversions would break it. User-generated content reaches these templates through Django's autoescaping, so it is always safe. {% endcomment %} {{ subject|default:brand_name }}
