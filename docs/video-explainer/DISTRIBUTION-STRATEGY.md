# DISTRIBUTION STRATEGY — Getting the Film Seen

The video is a weapon for a specific campaign: **establish Code Yaar as a credible
ed-tech startup** among (a) students/beginner developers in Pakistan (primary market,
board-curriculum fit), (b) educators/mentors who share resources, (c) investors/partners
who judge polish in 10 seconds.

## 1. Cutdown matrix (produce from the same master timeline)

| Format | Where | Content |
|---|---|---|
| 16:9 1080p, 58s | YouTube (hero), landing page embed | Full film |
| 9:16, 0–30s | Instagram Reels, TikTok, YouTube Shorts | Scenes 1→2→4 (problem → reveal → code-run moment). Hook = the live code run. Burn the tagline + URL at the end vertically |
| 1:1, 30s | Instagram/Facebook feed, LinkedIn post | Scenes 2→3→4→6→7 |
| GIF/WEBM ≤ 8 MB, 6s | Twitter/X, Discord, README | The Scene-4 run→output moment alone |
| 15s teaser, 9:16 | Paid-free booster: WhatsApp status, community posts | Logo reveal + code run + tagline |

Rules: captions/subtitles burned on all social cuts (most feed autoplay is muted —
the VO carries nothing there); keep text inside 14% safe margins; logo watermark tiny,
bottom-right, 60% opacity across all cuts.

## 2. Launch sequence (week-by-week, $0)

**T-7 days — seeding.** Export master early. Share with 5–10 trusted beta learners/
mentors for one round of notes. Screenshot 6 hero frames for posts.

**Day 0 — YouTube premiere + site swap.**
- Title pattern: `Code Yaar — Think. Build. Evolve. | Official Launch Film` (no clickbait).
- Description: 2-line mission + timestamped chapters (Learn/Practice/Build/Evolve) +
  sign-up link + tech stack honesty line ("all footage is the actual product").
- Card + end screen → sign-up page. Thumbnail: navy, logo, one UI panel, 4 words max.
- Same day: replace/insert the video on the landing page hero section (below the fold
  or in a "Watch the 60-second tour" button — decision for the owner, out of scope here).

**Day 0–2 — owned channels.** LinkedIn (founding-story caption: why we built it, tag
  no one, let the film talk), X thread (film GIF + 5 screenshots with micro-story),
  Instagram Reels + TikTok, YouTube Community, dev Discord/WhatsApp groups the team
  genuinely belongs to.

**Week 1 — communities (highest-leverage free channel).** Post where each community's
  rules allow: r/learnprogramming *only* if framed as "we built this, feedback welcome"
  and rules permit self-promo (many don't — read each subreddit's rules first); Pakistani
  dev Facebook/LinkedIn groups, CS student societies, Hacker News "Show HN" (weekdays,
  ~08:00 ET; be humble and technical in the post body). Every post: film first line,
  story second, link third.

**Week 2–3 — asset reuse.** Cut the 6s GIF into: README badge-video, email signature,
  certificate-verification page explainer, app-store/Play feature graphic, press-kit
  page (`/about` embed). Submit to free directories (Product Hunt launch planned
  separately — the 60s film is the PH hero asset; PH schedule Tuesday–Thursday).

## 3. Measurement (all free)

- YouTube Studio: avg view duration & retention graph → if >40% drop at Scene 1,
  shorten the problem beat to 4s for a v2.
- Landing page: sign-up conversion before/after 2 weeks (backend analytics dashboard
  already exists at `/admin/analytics`).
- UTM-tagged links (`?utm_source=linkedin&utm_medium=video` etc.) to see which
  channel converts, not just views.

## 4. What NOT to do

- Don't run it as a cold Facebook ad — a 58s film with no offer structure wastes money
  you don't have. The film's job is trust, not clicks.
- Don't repost the same link 5× per week to the same group — communities punish it.
- Don't add clickbait captions ("You've been learning code WRONG") — off-brand for a
  serious startup; the Scene-1 copy already makes that point with dignity.
- Don't chase every platform. YouTube + LinkedIn + Reels + 2 real communities, done well.
